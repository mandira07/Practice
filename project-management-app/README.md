# ProjectFlow - Project Management App

A beautiful and modern project management application built with React and TypeScript. This app features a stunning login page and a comprehensive dashboard for managing projects and tracking progress.

## 🌟 Features

### Authentication
- **Beautiful Login Page**: Modern glassmorphism design with animated background
- **Form Validation**: Real-time email and password validation
- **Loading States**: Smooth loading animations during authentication
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices

### Dashboard
- **Project Overview**: Statistics cards showing active projects, completed tasks, team members, and pending reviews
- **Recent Projects**: List of recent projects with status indicators
- **Modern UI**: Clean, professional interface with hover effects and animations
- **Responsive Layout**: Fully responsive design that adapts to all screen sizes

### Technical Features
- **TypeScript**: Full TypeScript support for better development experience
- **React Hooks**: Modern React patterns with hooks for state management
- **CSS3 Animations**: Smooth animations and transitions
- **Accessibility**: Focus management and keyboard navigation support
- **Modern CSS**: Uses CSS Grid, Flexbox, and modern CSS features

## 🚀 Getting Started

### Prerequisites
- Node.js (version 14 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd project-management-app
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the application.

## 📱 Usage

### Login
1. Enter any valid email address (e.g., `user@example.com`)
2. Enter a password with at least 6 characters
3. Click "Sign In" to access the dashboard
4. The app will simulate authentication with a loading state

### Dashboard
- View project statistics in the overview cards
- Browse recent projects with their current status
- Use the logout button to return to the login page
